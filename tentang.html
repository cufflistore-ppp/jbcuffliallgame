Tentang Kami

CUFFLI ALL GAME adalah marketplace akun game siap pakai (Free Fire, Mobile Legends, dan game populer lainnya) dilengkapi Spin Voucher dan CUFFLI Challenge biar belanja lebih hemat & seru.

Kenapa pilih kami?

• Akun original & aman
• Proses cepat setelah pembayaran dikonfirmasi
• Harga kompetitif + diskon produk
• Spin Voucher — putar roda, dapat diskon s.d. 30%
• Game Challenge — main mini-game, naik level, voucher s.d. 25%
• Chat CS (Asisten Cuffli) + WhatsApp admin 24/7 jam operasional
• Login member untuk notifikasi order

Cara Order Akun

1. Login / Daftar akun member
2. Pilih akun di beranda
3. Lihat detail & spek produk
4. Bayar via QRIS admin produk tersebut
5. Konfirmasi ke WhatsApp admin produk
6. Akun diproses & dikirim

Spin Voucher

1. Beli paket spin Rp 15.000 → konfirmasi admin
2. Admin kirim kode redeem (1 kode = 1× pakai)
3. Masukkan kode di menu Spin → dapat 3× putaran
4. Hasil: Zonk atau Voucher diskon 10% – 30%
5. Pakai voucher saat bayar produk di halaman pembayaran

CUFFLI Challenge (Game)

Main mini-game gratis: Hitung Cepat, Tebak Kata, Tebak Emoji, Memory Card.
Dapat EXP → naik level → voucher diskon di level milestone.
Max voucher game: 25% di Level 100 (naik level sengaja dibuat susah).
Voucher dari game bisa dipakai saat beli produk, sama seperti voucher spin.

Garansi

Setiap akun yang terjual dijamin bisa login. Jika ada masalah dalam 24 jam setelah terima, hubungi admin untuk penggantian. Allreff 24 jam — lewat 24 jam tidak berlaku.
